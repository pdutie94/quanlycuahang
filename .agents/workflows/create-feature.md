# Create Feature

## Steps

1. Analyze requirement

2. Split tasks:
    - backend (Slim4)
    - frontend (Vue3)

3. Backend:
    - create route
    - create controller (no business logic)
    - create service

4. Frontend:
    - create service for API
    - create component using TypeScript

5. Ensure:
    - no JavaScript in new code
    - types defined

## Output

- working feature
- explanation
