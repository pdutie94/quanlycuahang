# Debug Workflow

## Steps

1. Read error message

2. Find original source file
   (NOT compiled/minified files)

3. Trace cause step-by-step

4. Fix with minimal change

5. Add safety:
    - null checks
    - guards

6. Validate:
    - no new issues
    - logic unchanged

## Output

- root cause
- fixed code
- explanation
