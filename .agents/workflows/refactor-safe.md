# Safe Refactor

## Steps

1. Identify small improvement area

2. Ensure:
    - behavior remains identical

3. Apply:
    - add types
    - improve naming
    - extract small functions

4. DO NOT:
    - rewrite large parts
    - change architecture

5. Validate:
    - no functional change

## Output

- improved code
- explanation
